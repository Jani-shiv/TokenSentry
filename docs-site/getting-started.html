Get up and running with TokenSentry in minutes. Learn installation, basic usage, and best practices for prompt analysis, optimization, and validation.

Installation

Install TokenSentry

Get TokenSentry installed and configured in your environment.

PyPI (Recommended)

Install from PyPI with all optional dependencies

# Install with all optional dependencies
pip install -e ".[dev]"

# Or install with specific extras
pip install "tokensentry[openai-tokenizer]"
pip install "tokensentry[huggingface-tokenizer]"
pip install "tokensentry[sentencepiece]"

# Minimal install (core only)
pip install tokensentry

Requirements: Python 3.11+

Docker

Run TokenSentry in a container

# Pull the image
docker pull ghcr.io/jani-shiv/tokensentry:latest

# Run with volume mount
docker run -v $(pwd):/workspace -it tokensentry analyze /workspace/prompt.md

# With tokenizer
docker run -v $(pwd):/workspace -it tokensentry optimize /workspace/prompt.md --tokenizer tiktoken:gpt-4

From Source

Clone and install from GitHub

git clone https://github.com/Jani-shiv/TokenSentry.git
cd TokenSentry
pip install -e ".[dev]"

# Verify installation
tokensentry version
tokensentry --help

Requires Git and Python 3.11+

System Requirements

  • Python: 3.11 or higher
  • OS: Linux, macOS, Windows (WSL recommended)
  • Memory: 512MB minimum, 2GB recommended
  • Disk: ~200MB for installation
  • Optional: Docker for containerized usage
Quick Start

Your First Analysis in 30 Seconds

Run your first prompt analysis and see TokenSentry in action.

1

Create a Prompt File

Create a file called my-prompt.md with your prompt:

# My Prompt

Act as a senior software engineer.

Review this Python code for performance issues:

```python
def process_items(items):
    results = []
    for item in items:
        if item.is_valid():
            results.append(item.process())
    return results
```

Identify performance bottlenecks and suggest optimizations.
Provide specific code examples for improvements.
2

Run Analysis

Run TokenSentry to analyze your prompt:

tokensentry analyze my-prompt.md

Optimize & Validate

Optimize your prompt and validate the result:

# Optimize with balanced profile

tokensentry validate my-prompt.md optimized.md

# Check token savings
tokensentry analyze optimized.md --tokenizer tiktoken:gpt-4

Configuration

Configuration

Customize TokenSentry behavior with configuration files and environment variables.

Environment Variables

# Core settings
TOKENSENTRY_MAX_PROMPT_SIZE=10485760      # 10MB max prompt size
TOKENSENTRY_DEFAULT_TOKENIZER=character-estimate
TOKENSENTRY_DEFAULT_PROFILE=conservative
TOKENSENTRY_ENABLE_SECURITY_CHECKS=true
TOKENSENTRY_TIMEOUT_SECONDS=30

# Tokenizer settings
TOKENSENTRY_TIKTOKEN_CACHE_DIR=/path/to/cache
TOKENSENTRY_HF_CACHE_DIR=/path/to/hf/cache
TOKENSENTRY_HF_OFFLINE_MODE=false

# Skill settings
TOKENSENTRY_SKILL_DIRS=/custom/skills/path
TOKENSENTRY_AUTO_LOAD_SKILLS=true

# Benchmark settings
TOKENSENTRY_BENCHMARK_CORPUS=/path/to/corpus
TOKENSENTRY_BENCHMARK_RESULTS=/path/to/results

# API (future)
TOKENSENTRY_API_HOST=127.0.0.1
TOKENSENTRY_API_PORT=8000
TOKENSENTRY_API_ENABLED=false

Configuration File

Create .tokensentry.yaml in your project root:

# .tokensentry.yaml
default_tokenizer: "tiktoken:gpt-4"
default_optimization_profile: "balanced"
enable_security_checks: true
enable_quality_scoring: true
timeout_seconds: 60

max_prompt_size: 10485760
max_line_length: 10000

denied_patterns:
  - ".."
  - "~"
  - "secret"
  - "password"
  - "api_key"

allowed_read_paths:
  - "./prompts"
  - "./examples"

skills:
  auto_load: true
  directories:
    - "./custom-skills"
  default_skills:
    - "tokensentry-analyzer"
    - "tokensentry-optimizer"
    - "tokensentry-validator"

benchmarks:
  corpus_path: "./benchmarks/corpus"
  results_path: "./benchmarks/results"
  default_profiles: ["conservative", "balanced", "aggressive"]
  categories: ["software_engineering", "devops", "security"]

Project-Level Config

Override settings per project with tokensentry.config.yaml:

# tokensentry.config.yaml
project_name: "my-project"
version: "1.0.0"

analyzer:
  enable_security: true
  enable_quality: true
  max_findings: 50

optimizer:
  default_profile: "balanced"
  preserve_literals: true
  max_iterations: 3

validator:
  strict_mode: true
  check_negative_constraints: true
  check_schema_preservation: true

tokenizer:
  default: "tiktoken:gpt-4"
  fallback: "character-estimate"

skills:
  enabled:
    - "tokensentry-analyzer"
    - "tokensentry-optimizer"
    - "tokensentry-validator"
    - "tokensentry-security-auditor"
    - "tokensentry-cost-analyst"
  custom_skills:
    - "./skills/my-custom-skill"
Troubleshooting

Common Issues & Solutions

Import Error: No module named 'tokensentry'

Cause: Package not installed or not in PATH

Solution:

# Reinstall with pip
pip install --force-reinstall -e ".[dev]"

# Or verify installation
python -c "import tokensentry; print(tokensentry.__version__)"

Tokenizer Not Found

Cause: Optional tokenizer dependencies not installed

Solution:

# Install specific tokenizer
pip install tokensentry[openai-tokenizer]    # For tiktoken
pip install tokensentry[huggingface-tokenizer]  # For HF models
pip install tokensentry[sentencepiece]        # For SentencePiece

# Or install all
pip install "tokensentry[all]"

Memory Error on Large Prompts

Cause: Prompt exceeds memory limit

Solution:

# Increase limit via env var
export TOKENSENTRY_MAX_PROMPT_SIZE=52428800  # 50MB

# Or in config
# max_prompt_size: 52428800

Tokenizer Model Not Found

Cause: HuggingFace model not cached or unavailable

Solution:

# Pre-download model
python -c "from transformers import AutoTokenizer; AutoTokenizer.from_pretrained('meta-llama/Llama-2-7b-hf')"

# Or use offline mode
export TOKENSENTRY_HF_OFFLINE_MODE=true

Validation Fails Unexpectedly

Cause: Optimizer removed required elements

Solution:

# Use conservative profile
tokensentry optimize prompt.md --profile conservative

# Check what was removed
tokensentry validate original.md optimized.md --format json

# Add explicit preservation
# tokensentry optimize prompt.md --preserve "requirement1,requirement2"

Slow Performance

Cause: Large prompts or complex analysis

Solution:

# Use character estimate for speed
tokensentry analyze huge-prompt.md --tokenizer character-estimate

# Disable heavy analysis
export TOKENSENTRY_ENABLE_SECURITY_CHECKS=false
export TOKENSENTRY_ENABLE_QUALITY_SCORING=false

# Profile specific sections
tokensentry benchmark run --max-prompts 1 --profiles conservative
FAQ

Frequently Asked Questions

What is TokenSentry and why should I use it?

TokenSentry is a local-first prompt intelligence toolkit that helps you analyze, optimize, and validate AI prompts. It runs entirely locally with no API keys required, providing deep insights into prompt structure, token usage, quality metrics, and security risks. It's designed for developers, prompt engineers, and AI practitioners who want to improve their prompts systematically.

Is TokenSentry free and open source?

Yes! TokenSentry is open source under the Apache 2.0 license. It's free to use, modify, and distribute. There are no paid tiers, no API keys required, and no usage limits. All processing happens locally on your machine.

Which Python versions are supported?

TokenSentry requires Python 3.11 or higher. We test against Python 3.11, 3.12, and 3.13. Older versions are not supported due to typing features and standard library dependencies.

Does TokenSentry send my prompts to external servers?

No. TokenSentry is completely local-first. Your prompts never leave your machine. All analysis, optimization, and validation happens locally. Optional tokenizer adapters (like HuggingFace) may download model weights on first use, but prompt content never leaves your machine.

Which tokenizers are supported?

TokenSentry supports: tiktoken (OpenAI models: GPT-4, GPT-3.5, GPT-4o, etc.), HuggingFace tokenizers (Llama, Mistral, Gemma, etc.), SentencePiece (custom models), and a built-in character-estimate fallback. Run tokensentry tokenizers to see all available options.

What's the difference between optimization profiles?

Conservative: Only removes redundant whitespace and exact duplicate lines. Safest option.
Balanced: Consolidates repeated phrases, removes redundant transitions, normalizes bullets. Good balance of safety and token reduction.
Aggressive: Removes filler sentences, compresses explanations, reorganizes sections. Maximum token reduction but with warnings. Always review aggressive output before use.

How accurate are the token counts?

Token counts are exact when using tiktoken or HuggingFace tokenizers. The character-estimate tokenizer provides estimates (~4 chars per token) and is clearly labeled as such. Never compare token counts from different tokenizers directly—they use different vocabularies and encoding schemes.

Can I use TokenSentry in CI/CD pipelines?

Yes! TokenSentry is designed for automation. All commands support --format json for machine-readable output. Exit codes indicate success/failure. Example CI usage: tokensentry validate original.md optimized.md --format json || exit 1. See CI/CD Integration for complete examples.

How do I create a custom skill?

Create a Python class inheriting from BaseSkill, define metadata with SkillMetadata, implement the execute() method, and register with the skill registry. See Creating Custom Skills for a complete tutorial with examples.

Can I extend TokenSentry with custom tokenizers?

Yes! Implement the BaseTokenizer interface and register with register_tokenizer(). Your tokenizer must provide count(), name, count_kind, and metadata. See Custom Tokenizers for a complete guide.

How do I report a bug or request a feature?

Open an issue on GitHub Issues. For security vulnerabilities, use GitHub's private vulnerability reporting. Please include: Python version, TokenSentry version, OS, steps to reproduce, and expected vs actual behavior.

Can I contribute to TokenSentry?

Absolutely! We welcome contributions. See Contributing Guide for guidelines on code contributions, documentation, testing, and skill development. All contributions are licensed under Apache 2.0.
