PROFILES

OPTIMIZATION PROFILES

CHOOSE THE RIGHT BALANCE OF TOKEN REDUCTION AND SAFETY FOR YOUR USE CASE.

CONSERVATIVE

SAFEST PROFILE. ONLY NORMALIZES WHITESPACE AND REMOVES EXACT DUPLICATE LINES. ZERO SEMANTIC CHANGES.

  • WHITESPACE NORMALIZATION
  • EXACT DUPLICATE LINE REMOVAL
  • TRAILING SPACE TRIMMING
  • MULTIPLE BLANK LINE COLLAPSE
  • ZERO SEMANTIC MODIFICATIONS
tokensentry optimize prompt.md --output opt.md
# OR EXPLICITLY
tokensentry optimize prompt.md --profile conservative --output opt.md

TOKEN REDUCTION: 5-15% | RISK: MINIMAL

BALANCED

RECOMMENDED DEFAULT. CONSOLIDATES REPEATED PHRASES, REMOVES REDUNDANT TRANSITIONS, NORMALIZES BULLET STYLES.

  • PHRASE CONSOLIDATION (4-GRAM DEFAULT)
  • REDUNDANT TRANSITION REMOVAL
  • BULLET STYLE NORMALIZATION
  • CONNECTIVE PHRASE SIMPLIFICATION
  • TECHNICAL LITERAL PRESERVATION
tokensentry optimize prompt.md --profile balanced --output opt.md

TOKEN REDUCTION: 15-30% | RISK: LOW

AGGRESSIVE

MAXIMUM REDUCTION. REMOVES FILLER SENTENCES, COMPRESSES EXPLANATIONS, REORGANIZES SECTIONS. ALWAYS REVIEW OUTPUT.

  • FILLER SENTENCE REMOVAL
  • EXPLANATION COMPRESSION
  • SECTION REORGANIZATION
  • REDUNDANT EXAMPLE TRIMMING
  • VERBOSE PHRASE REPLACEMENT
tokensentry optimize prompt.md --profile aggressive --output opt.md

TOKEN REDUCTION: 30-50% | RISK: MODERATE

LITERAL PRESERVATION

TECHNICAL LITERALS ARE AUTOMATICALLY DETECTED AND PRESERVED:

  • CODE IDENTIFIERS: function_name, ClassName, variable_name
  • API KEYS & TOKENS: sk-..., ghp_..., Bearer ...
  • MODEL NAMES: GPT-4, Llama-2-7b, text-embedding-ada-002
  • FILE PATHS: /path/to/file.py, ./src/main.rs
  • VERSION STRINGS: v1.2.3, 2024-01-15
  • CUSTOM: USE --preserve "TERM1,TERM2"
CONFIGURATION

OPTIMIZER CONFIGURATION

# .tokensentry.yaml
optimizer:
  default_profile: "balanced"
  preserve_literals: true
  max_iterations: 3
  
  conservative:
    normalize_whitespace: true
    remove_exact_duplicates: true
    
  balanced:
    phrase_consolidation: true
    min_phrase_length: 4
    similarity_threshold: 0.85
    transition_removal: true
    bullet_normalization: true
    
  aggressive:
    filler_removal: true
    explanation_compression: true
    section_reorganization: true
    example_trimming: true
    verbose_replacement: true

BEST PRACTICES

OPTIMIZATION BEST PRACTICES

START CONSERVATIVE

BEGIN WITH CONSERVATIVE PROFILE. ESCALATE ONLY IF NEEDED.

tokensentry optimize prompt.md --profile conservative --output v1.md
tokensentry validate prompt.md v1.md

USE EXACT TOKENIZERS

GET ACCURATE TOKEN COUNTS WITH TIKTOKEN OR HF TOKENIZERS.

tokensentry optimize prompt.md --profile balanced \
  --tokenizer tiktoken:gpt-4 --output opt.md

ALWAYS VALIDATE

RUN VALIDATOR AFTER EVERY OPTIMIZATION TO CATCH REGRESSIONS.

tokensentry validate original.md optimized.md --strict

PRESERVE CRITICAL TERMS

EXPLICITLY PRESERVE DOMAIN-SPECIFIC TERMINOLOGY.

tokensentry optimize prompt.md --profile aggressive \
  --preserve "JWT,OAuth2,REST API,GraphQL" --output opt.md

COMPARE PROFILES

RUN MULTIPLE PROFILES AND COMPARE RESULTS.

for p in conservative balanced aggressive; do
  tokensentry optimize prompt.md --profile $p --output opt_$p.md
done

# GITHUB ACTIONS
