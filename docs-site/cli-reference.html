ANALYZE

TOKENSENTRY ANALYZE

ANALYZE PROMPT STRUCTURE, QUALITY, TOKENS, AND SECURITY.

tokensentry analyze PROMPT_FILE [OPTIONS]

ARGUMENTS:
  PROMPT_FILE    PATH TO PROMPT FILE (.MD, .TXT, OR - FOR STDIN)

OPTIONS:
  -f, --format FORMAT        OUTPUT FORMAT: TEXT, JSON, MARKDOWN
  -t, --tokenizer TOKENIZER  TOKENIZER TO USE
  --enable-security          ENABLE SECURITY ANALYSIS
  --enable-quality           ENABLE QUALITY SCORING
  --max-findings N           MAXIMUM FINDINGS TO REPORT
  --output FILE              WRITE OUTPUT TO FILE

EXAMPLES

BASIC ANALYSIS

tokensentry analyze prompt.md

WITH GPT-4 TOKENIZER

tokensentry analyze prompt.md --tokenizer tiktoken:gpt-4

JSON FOR SCRIPTING

tokensentry analyze prompt.md --format json | jq .

MARKDOWN REPORT

tokensentry analyze prompt.md --format markdown > report.md

FULL ANALYSIS

tokensentry analyze prompt.md \
  --tokenizer tiktoken:gpt-4 \
  --enable-security \
  --enable-quality \
  --format json

FROM STDIN

cat prompt.md | tokensentry analyze - --format json

OPTIMIZE

TOKENSENTRY OPTIMIZE

OPTIMIZE PROMPTS WITH THREE PROFILES: CONSERVATIVE, BALANCED, AGGRESSIVE.

tokensentry optimize PROMPT_FILE [OPTIONS]

ARGUMENTS:
  PROMPT_FILE    PATH TO PROMPT FILE

OPTIONS:
  -p, --profile PROFILE      OPTIMIZATION PROFILE: CONSERVATIVE, BALANCED, AGGRESSIVE
  -o, --output FILE          OUTPUT FILE PATH (REQUIRED)
  -t, --tokenizer TOKENIZER  TOKENIZER FOR EXACT COUNTS
  --preserve LIST            COMMA-SEPARATED LIST OF STRINGS TO PRESERVE
  --max-iterations N         MAX OPTIMIZATION ITERATIONS (DEFAULT: 3)
  --format FORMAT            OUTPUT FORMAT: TEXT, JSON, MARKDOWN

PROFILE COMPARISON

PROFILEDESCRIPTIONTOKEN REDUCTIONRISK LEVEL
CONSERVATIVEWHITESPACE NORMALIZATION, EXACT DUPLICATE REMOVAL ONLY5-15%MINIMAL
BALANCEDPHRASE CONSOLIDATION, REDUNDANT TRANSITION REMOVAL, BULLET NORMALIZATION15-30%LOW
AGGRESSIVEFILLER SENTENCE REMOVAL, EXPLANATION COMPRESSION, SECTION REORGANIZATION30-50%MODERATE

EXAMPLES

CONSERVATIVE (DEFAULT)

tokensentry optimize prompt.md --output optimized.md

BALANCED PROFILE

tokensentry optimize prompt.md --profile balanced --output opt.md

AGGRESSIVE PROFILE

tokensentry optimize prompt.md --profile aggressive --output opt.md

WITH EXACT TOKENIZER

tokensentry optimize prompt.md --profile balanced \
  --tokenizer tiktoken:gpt-4 --output opt.md

PRESERVE SPECIFIC STRINGS

tokensentry optimize prompt.md --profile balanced \
  --preserve "MUST INCLUDE,REQUIRED" --output opt.md

JSON OUTPUT

tokensentry optimize prompt.md --profile balanced \
  --output opt.md --format json

TOKENSENTRY VALIDATE

VALIDATE OPTIMIZED PROMPTS AGAINST ORIGINALS WITH 7-STATUS CLASSIFICATION.

OPTIONS:

  --output FILE              WRITE OUTPUT TO FILE

SKILLS

TOKENSENTRY SKILL / WORKFLOW

RUN INDIVIDUAL SKILLS OR COMPOSE WORKFLOWS.

LIST SKILLS

tokensentry skill list [--format FORMAT]

RUN SINGLE SKILL

tokensentry skill run SKILL_NAME [OPTIONS]

OPTIONS:
  --prompt TEXT       PROMPT TEXT (OR USE --prompt-file)
  --prompt-file FILE  PATH TO PROMPT FILE
  --format FORMAT     OUTPUT FORMAT: TEXT, JSON, MARKDOWN
  --config FILE       SKILL-SPECIFIC CONFIG FILE

RUN WORKFLOW

tokensentry workflow run PLAN_NAME [OPTIONS]

BUILT-IN PLANS:

BENCHMARKS

TOKENSENTRY BENCHMARK

RUN BENCHMARKS ON CURATED PROMPT CORPUS.

tokensentry benchmark run [OPTIONS]

OPTIONS:
  --profiles LIST          PROFILES TO RUN: CONSERVATIVE, BALANCED, AGGRESSIVE
  --max-prompts N          MAXIMUM PROMPTS TO PROCESS
  --categories LIST        CATEGORIES TO INCLUDE
  --tokenizer TOKENIZER    TOKENIZER FOR EXACT COUNTS
  --output FILE            SAVE RESULTS TO FILE
  --format FORMAT          OUTPUT FORMAT: TEXT, JSON

REPORT GENERATION

tokensentry benchmark report RESULTS_FILE [OPTIONS]

OPTIONS:
  --format FORMAT    OUTPUT FORMAT: TEXT, MARKDOWN, JSON
  --output FILE      WRITE REPORT TO FILE
  --compare          COMPARE AGAINST BASELINE

EXAMPLES

RUN ALL BENCHMARKS

tokensentry benchmark run

SPECIFIC PROFILES

tokensentry benchmark run --profiles conservative balanced

LIMIT PROMPTS

tokensentry benchmark run --max-prompts 5

SAVE & REPORT

tokensentry benchmark run --output results.json
tokensentry benchmark report results.json --format markdown
CI/CD INTEGRATION

CONTINUOUS INTEGRATION

USE TOKENSENTRY IN YOUR CI/CD PIPELINES.

GITHUB ACTIONS

# .github/workflows/tokensentry.yml
name: TokenSentry Validation

on: [push, pull_request]

jobs:
  validate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.11'
      - name: Install TokenSentry
        run: pip install tokensentry[openai-tokenizer]
      - name: Validate Prompts
        run: |
          tokensentry validate prompts/original.md prompts/optimized.md \
            --tokenizer tiktoken:gpt-4 --strict --format json
      - name: Analyze Prompt Quality
        run: |
          tokensentry analyze prompts/main.md \
            --tokenizer tiktoken:gpt-4 --format json > analysis.json
      - name: Upload Analysis
        uses: actions/upload-artifact@v4
        with:
          name: tokensentry-analysis
          path: analysis.json

GITLAB CI

# .gitlab-ci.yml
tokensentry_validate:
  stage: test
  image: python:3.11-slim
  script:
    - pip install tokensentry[openai-tokenizer]
    - tokensentry validate prompts/original.md prompts/optimized.md --strict --format json
  artifacts:
    reports:
      junit: tokensentry-report.xml
    when: always
