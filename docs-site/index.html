Welcome to TokenSentry

TokenSentry is a local-first prompt intelligence toolkit that helps you analyze, optimize, and validate AI prompts. It runs entirely on your machine with no API keys required, providing deep insights into prompt structure, token usage, quality metrics, and security risks.

Core Engines

TokenSentry is built around three core engines that work together to give you complete prompt intelligence:

🔍 Analyzer

7 modular analyzers: Structure, Redundancy, Ambiguity, Contradictions, Complexity, Quality, Security. Quality scores across 6 dimensions.

⚡ Optimizer

3 profiles (Conservative/Balanced/Aggressive), technical literal preservation, transformation delta tracking, multi-pass iteration.

✅ Validator

7-status classification (Exact/Structural/Probable/Uncertain/Modified/Missing/Weakened), byte-for-byte literal verification, CI/CD ready.

Key Features

  • Exact Token Counting: Tiktoken (OpenAI), HuggingFace tokenizers, SentencePiece — no silent fallbacks, explicit exactness metadata.
  • 15 AI Agent Skills: Composable skills for analysis, optimization, validation, security auditing, cost analysis, context engineering, and workflow orchestration.
  • Rich Reporting: JSON, Markdown, and beautiful terminal output with syntax highlighting and schema versioning.
  • Local-First: Zero external API calls, complete privacy, works offline.
  • CI/CD Ready: Exit codes, JSON output, GitHub Actions integration.

Quick Example

# Install
pip install -e ".[dev]"

# Analyze a prompt
tokensentry analyze prompt.md --tokenizer tiktoken:gpt-4

# Optimize with balanced profile
tokensentry optimize prompt.md --profile balanced --output optimized.md

# Validate preservation
tokensentry validate prompt.md optimized.md --format json

Requirements

  • Python: 3.11 or higher
  • OS: Linux, macOS, Windows (WSL recommended)
  • Memory: 512MB minimum, 2GB recommended
  • Optional: Docker for containerized usage
