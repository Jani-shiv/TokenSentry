Core Features

Everything you need for prompt intelligence

TokenSentry provides a complete toolkit for understanding, measuring, optimizing, and validating AI prompts — all locally, with no API keys required.

Deep Analysis

7 modular analyzers detect structure, redundancy, ambiguity, contradictions, complexity, quality issues, and security risks.

  • Structure parsing (headings, code fences, lists)
  • Redundancy detection (lines, phrases, requirements)
  • Ambiguity & contradiction detection
  • Complexity metrics & quality scoring
  • Security audit (injection, secrets, unsafe)

    • Smart Optimization

    Three profiles — Conservative, Balanced, Aggressive — with full transformation tracking and technical literal preservation.

    • Conservative: whitespace, duplicates only
    • Balanced: phrase consolidation, transitions
    • Aggressive: filler removal, compression
    • Technical literal preservation
    • Transformation delta tracking

    Semantic Validation

    7-status classification (exact/structural/probable/uncertain/modified/missing/weakened) with byte-for-byte literal preservation.

    • Requirement preservation checking
    • Negative constraint weakening detection
    • Technical literal byte-for-byte verification
    • Output schema preservation
    • Detailed diff with confidence scores

    Tokenizer Support

    Exact token counting with tiktoken (OpenAI), HuggingFace tokenizers, SentencePiece — no silent fallbacks, explicit exactness metadata.

    • tiktoken: GPT-4, GPT-3.5, GPT-4o, etc.
    • HuggingFace: Llama, Mistral, Gemma, etc.
    • SentencePiece: custom models
    • Exact vs estimate classification
    • Model-aware context window warnings

    15 AI Agent Skills

    Composable, reusable skills for analyzer, optimizer, validator, security auditor, cost analyst, and more.

    • Analyzer, Optimizer, Validator, Token Auditor
    • Security Auditor, Context Engineer
    • Cost Analyst, Model Adapter
    • Skill Composer for orchestration
    • Structured Output, Few-Shot, Agent Workflow

    Rich Reporting

    Export results as JSON, Markdown, or beautiful terminal output with syntax highlighting and interactive tables.

    • JSON export with schema versioning
    • Markdown reports for documentation
    • Rich terminal UI with tables
    • Benchmark comparison reports
    • Schema versioning for compatibility
    Quick Start

    Get running in 30 seconds

    Run your first prompt analysis and see TokenSentry in action.

    1

    Install TokenSentry

    pip install -e ".[dev]"

    Requires Python 3.11+. Installs with all dependencies including optional tokenizer adapters.

    2

    Analyze a Prompt

    tokensentry analyze examples/sample-prompt.md

    Get structure analysis, quality scores, token counts, and findings instantly.

    3

    Optimize & Validate

    tokensentry optimize prompt.md --profile balanced --output optimized.md
tokensentry validate prompt.md optimized.md

    Choose conservative, balanced, or aggressive profiles. Validate preserves requirements.

    Pro Tip: Use --tokenizer tiktoken:gpt-4 for exact GPT-4 token counts, or --tokenizer hf:meta-llama/Llama-2-7b-hf for Llama models. Run tokensentry tokenizers to see all available options.

    Examples

    Common Workflows

    Real-world examples showing TokenSentry in action.

    # Basic analysis
tokensentry analyze prompt.md

# With specific tokenizer
tokensentry analyze prompt.md --tokenizer tiktoken:gpt-4

# JSON output for scripting
tokensentry analyze prompt.md --format json

# Markdown report
tokensentry analyze prompt.md --format markdown
    # Conservative (default) - whitespace only
tokensentry optimize prompt.md --output optimized.md

# Balanced - phrase consolidation, transitions
tokensentry optimize prompt.md --profile balanced --output opt.md

# Aggressive - filler removal, compression
tokensentry optimize prompt.md --profile aggressive --output opt.md

# With specific tokenizer for exact counts
tokensentry optimize prompt.md --profile balanced \
  --tokenizer tiktoken:gpt-4 --output opt.md
    # Validate optimized against original
tokensentry validate original.md optimized.md

# With specific tokenizer
tokensentry validate original.md optimized.md --tokenizer tiktoken:gpt-4

# JSON output for CI/CD
tokensentry validate original.md optimized.md --format json
    # List all skills
tokensentry skill list

# Run a single skill
tokensentry skill run tokensentry-analyzer \
  --prompt "Your prompt here"

# Run a composition plan
tokensentry workflow run standard \
  --prompt "Your prompt here"

# Custom composition
tokensentry workflow run custom \
  --steps '["tokensentry-analyzer", "tokensentry-optimizer", "tokensentry-validator"]' \
  --prompt "Your prompt here"
    # Run all benchmarks
tokensentry benchmark run

# Specific profiles only
tokensentry benchmark run --profiles conservative balanced

# Limit prompts
tokensentry benchmark run --max-prompts 5

# Save results
tokensentry benchmark run --output results.json

# Generate reports
tokensentry benchmark report results.json --format markdown
