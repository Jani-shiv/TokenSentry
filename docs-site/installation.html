GET TOKENSENTRY INSTALLED IN YOUR ENVIRONMENT. SUPPORTS PYPI, DOCKER, AND SOURCE INSTALLATION. REQUIRES PYTHON 3.11+.

PYPI INSTALL DOCKER
PYPI

INSTALL FROM PYPI (RECOMMENDED)

FULL INSTALL (ALL DEPENDENCIES)

INCLUDES ALL OPTIONAL TOKENIZER ADAPTERS AND DEV TOOLS

pip install -e ".[dev]"

INSTALLS: CORE + TIKTOKEN + HUGGINGFACE + SENTENCEPIECE + TESTING + LINTERS

SPECIFIC EXTRAS

INSTALL ONLY WHAT YOU NEED

# OPENAI TIKTOKEN ONLY
pip install "tokensentry[openai-tokenizer]"

# HUGGINGFACE TOKENIZERS ONLY
pip install "tokensentry[huggingface-tokenizer]"

# SENTENCEPIECE ONLY
pip install "tokensentry[sentencepiece]"

# ALL TOKENIZERS
pip install "tokensentry[all-tokenizers]"

# DEV TOOLS ONLY
pip install "tokensentry[dev]"

# ALL EXTRAS
pip install "tokensentry[all]"

MINIMAL INSTALL (CORE ONLY)

NO OPTIONAL DEPENDENCIES - CHARACTER ESTIMATE TOKENIZER ONLY

pip install tokensentry

USES BUILT-IN CHARACTER-ESTIMATE TOKENIZER (~4 CHARS/TOKEN)

REQUIREMENTS

  • PYTHON: 3.11, 3.12, OR 3.13
  • PIP: 23.0+ RECOMMENDED
  • OS: LINUX, MACOS, WINDOWS (WSL RECOMMENDED)
  • MEMORY: 512MB MINIMUM, 2GB RECOMMENDED
  • DISK: ~200MB FOR FULL INSTALL
DOCKER

DOCKER INSTALLATION

GITHUB CONTAINER REGISTRY

PULL FROM GHCR.IO

# PULL LATEST
docker pull ghcr.io/jani-shiv/tokensentry:latest

# PULL SPECIFIC VERSION
docker pull ghcr.io/jani-shiv/tokensentry:v0.1.1

RUN COMMANDS

MOUNT WORKSPACE VOLUME FOR FILE ACCESS

# ANALYZE
docker run -v $(pwd):/workspace -it ghcr.io/jani-shiv/tokensentry:latest \
  analyze /workspace/prompt.md

# OPTIMIZE
docker run -v $(pwd):/workspace -it ghcr.io/jani-shiv/tokensentry:latest \
  optimize /workspace/prompt.md --profile balanced --output /workspace/optimized.md

# VALIDATE
docker run -v $(pwd):/workspace -it ghcr.io/jani-shiv/tokensentry:latest \
  validate /workspace/original.md /workspace/optimized.md

# WITH TIKTOKEN
docker run -v $(pwd):/workspace -it ghcr.io/jani-shiv/tokensentry:latest \
  analyze /workspace/prompt.md --tokenizer tiktoken:gpt-4

DOCKER COMPOSE

FOR REPEATED USE IN PROJECTS

# docker-compose.yml
version: '3.8'
services:
  tokensentry:
    image: ghcr.io/jani-shiv/tokensentry:latest
    volumes:
      - .:/workspace
    working_dir: /workspace
    entrypoint: ["tokensentry"]
    command: ["--help"]

USAGE: docker-compose run tokensentry analyze prompt.md

TROUBLESHOOTING

COMMON INSTALLATION ISSUES

IMPORT ERROR: NO MODULE NAMED 'TOKENSENTRY'

CAUSE: PACKAGE NOT INSTALLED OR NOT IN PYTHON PATH

SOLUTION:

# REINSTALL
pip install --force-reinstall -e ".[dev]"

# VERIFY
python -c "import tokensentry; print(tokensentry.__version__)"

TOKENIZER NOT FOUND

CAUSE: OPTIONAL DEPENDENCIES NOT INSTALLED

SOLUTION:

# INSTALL SPECIFIC TOKENIZER
pip install tokensentry[openai-tokenizer]
pip install tokensentry[huggingface-tokenizer]
pip install tokensentry[sentencepiece]

# OR ALL
pip install "tokensentry[all]"

PYTHON VERSION ERROR

CAUSE: PYTHON < 3.11

SOLUTION:

# CHECK VERSION
python --version

# USE PYENV OR CONDA FOR 3.11+
pyenv install 3.11.9
pyenv local 3.11.9

# OR CONDA
conda create -n tokensentry python=3.11
conda activate tokensentry

PERMISSION ERROR ON INSTALL

CAUSE: NO WRITE ACCESS TO SITE-PACKAGES

SOLUTION:

# USE --USER FLAG
pip install --user -e ".[dev]"

# OR VIRTUAL ENVIRONMENT (RECOMMENDED)
python -m venv .venv
source .venv/bin/activate  # LINUX/MAC
.venv\Scripts\activate     # WINDOWS
pip install -e ".[dev]"

HUGGINGFACE MODEL DOWNLOAD FAILS

CAUSE: NETWORK ISSUES OR RATE LIMITS

SOLUTION:

# PRE-DOWNLOAD MODEL
python -c "from transformers import AutoTokenizer; AutoTokenizer.from_pretrained('meta-llama/Llama-3-8b')"

# USE OFFLINE MODE
export TOKENSENTRY_HF_OFFLINE_MODE=true
export HF_HOME=/path/to/cache

MEMORY ERROR DURING INSTALL

CAUSE: LARGE DEPENDENCIES (TRANSFORMERS, TORCH)

SOLUTION:

# INSTALL MINIMAL FIRST
pip install tokensentry

# THEN ADD TOKENIZERS ONE BY ONE
pip install tokensentry[openai-tokenizer]
pip install tokensentry[huggingface-tokenizer]
