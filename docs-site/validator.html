FEATURES

VALIDATION CAPABILITIES

LITERAL PRESERVATION

BYTE-FOR-BYTE VERIFICATION OF TECHNICAL LITERALS: CODE IDENTIFIERS, API KEYS, MODEL NAMES, FILE PATHS, VERSION STRINGS.

  • AUTOMATIC DETECTION OF TECHNICAL TERMS
  • CUSTOM PRESERVATION LISTS SUPPORTED
  • CASE-SENSITIVE EXACT MATCHING
  • POSITION-INDEPENDENT VERIFICATION

NEGATIVE CONSTRAINT CHECKING

DETECTS WHEN PROHIBITIONS ARE WEAKENED OR REMOVED: "DO NOT", "NEVER", "MUST NOT", "AVOID", "PROHIBITED".

  • PATTERN-BASED NEGATION DETECTION
  • WEAKENING SEVERITY CLASSIFICATION
  • CONTEXT-AWARE ANALYSIS
  • CRITICAL FAILURE ON WEAKENING

SCHEMA VALIDATION

VALIDATES OUTPUT FORMAT PRESERVATION: JSON SCHEMA, MARKDOWN STRUCTURE, YAML FORMAT, CUSTOM TEMPLATES.

  • JSON SCHEMA DRAFT 7 SUPPORT
  • MARKDOWN HEADING HIERARCHY CHECK
  • YAML STRUCTURE VALIDATION
  • CUSTOM REGEX PATTERN MATCHING

DIFF WITH CONFIDENCE

DETAILED DIFF OUTPUT WITH PER-REQUIREMENT CONFIDENCE SCORES FOR TRACEABLE DECISIONS.

  • SIDE-BY-SIDE COMPARISON
  • CONFIDENCE SCORES (0.0-1.0)
  • EVIDENCE SNIPPETS
  • LINE-LEVEL LOCATIONS

STRICT MODE

STRICT MODE FOR CI/CD

ENABLE STRICT MODE TO FAIL ON ANY NON-PASSED REQUIREMENT.

# STRICT MODE - FAILS ON PROBABLE, UNCERTAIN, MODIFIED, WEAKENED, MISSING
tokensentry validate original.md optimized.md --strict

# COMBINED WITH JSON FOR AUTOMATION
tokensentry validate original.md optimized.md --strict --format json || exit 1

# GITHUB ACTIONS EXAMPLE
- name: Validate Optimized Prompt
  run: |
    tokensentry validate prompts/original.md prompts/optimized.md \
      --tokenizer tiktoken:gpt-4 --strict --format json
