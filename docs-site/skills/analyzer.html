TOKENSENTRY-ANALYZER DEEP PROMPT ANALYSIS

RUN THE FULL ANALYSIS PIPELINE AS A COMPOSABLE SKILL. 7 MODULAR ANALYZERS: STRUCTURE, REDUNDANCY, AMBIGUITY, CONTRADICTIONS, COMPLEXITY, QUALITY, SECURITY.

ALL SKILLS CLI REFERENCE
USAGE

RUNNING THE ANALYZER SKILL

CLI - BASIC

tokensentry skill run tokensentry-analyzer \
  --prompt "YOUR PROMPT HERE"

CLI - WITH FILE

tokensentry skill run tokensentry-analyzer \
  --prompt-file prompt.md

CLI - WITH TIKTOKEN

tokensentry skill run tokensentry-analyzer \
  --prompt-file prompt.md \
  --tokenizer tiktoken:gpt-4

CLI - JSON OUTPUT

tokensentry skill run tokensentry-analyzer \
  --prompt-file prompt.md \
  --format json

PYTHON API

from tokensentry.skills import SkillRegistry

registry = SkillRegistry()
registry.auto_load()

analyzer = registry.get("tokensentry-analyzer")

# RUN WITH PROMPT TEXT
result = analyzer.execute(prompt="YOUR PROMPT HERE")

# RUN WITH PROMPT OBJECT
from tokensentry.models import Prompt
prompt = Prompt.from_file("prompt.md")
result = analyzer.execute(prompt=prompt)

# ACCESS RESULTS
print(result.success)
print(result.data)
print(result.metadata)

MODULES

ANALYSIS MODULES

STRUCTURE

PARSES MARKDOWN: HEADINGS, CODE FENCES, LISTS, TABLES, LINKS, IMAGES, BLOCKQUOTES.

REDUNDANCY

DETECTS DUPLICATE LINES, REPEATED PHRASES (4-GRAM), REDUNDANT REQUIREMENTS.

AMBIGUITY

IDENTIFIES VAGUE TERMS: RELATIVE WITHOUT SCALE, UNQUALIFIED QUANTIFIERS, MISSING CONTEXT.

CONTRADICTIONS

FINDS CONFLICTING INSTRUCTIONS, MUTUALLY EXCLUSIVE REQUIREMENTS, CONSTRAINT CONFLICTS.

COMPLEXITY

GUNNING FOG, FLESCH-KINCAID, ARI, COLEMAN-LIAU, SYNTACTIC DEPTH, VOCABULARY DIVERSITY.

QUALITY

6 DIMENSIONS: CLARITY, COMPLETENESS, STRUCTURE, CONCISENESS, ACTIONABILITY, OVERALL (0-1).

SECURITY (OPTIONAL)

PROMPT INJECTION, SECRET LEAKAGE, ROLE OVERRIDE, UNSAFE OUTPUT REQUESTS.
