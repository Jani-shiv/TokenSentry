USAGE

USING SKILLS

LIST ALL SKILLS

tokensentry skill list

RUN SINGLE SKILL

# WITH PROMPT TEXT
tokensentry skill run tokensentry-analyzer --prompt "YOUR PROMPT HERE"

# WITH PROMPT FILE
tokensentry skill run tokensentry-optimizer --prompt-file prompt.md --profile balanced

# JSON OUTPUT
tokensentry skill run tokensentry-validator --prompt-file original.md --prompt-file-optimized optimized.md --format json

RUN WORKFLOW

# BUILT-IN PLANS
tokensentry workflow run standard --prompt-file prompt.md
tokensentry workflow run security --prompt-file prompt.md

# CUSTOM WORKFLOW
tokensentry workflow run custom \
  --steps '["tokensentry-analyzer", "tokensentry-optimizer", "tokensentry-validator"]' \
  --prompt-file prompt.md

PYTHON API

from tokensentry.skills import SkillRegistry, SkillMetadata
from tokensentry.skills.analyzer import AnalyzerSkill
from tokensentry.skills.optimizer import OptimizerSkill
from tokensentry.skills.validator import ValidatorSkill

# REGISTRY
registry = SkillRegistry()
registry.auto_load()

# RUN SINGLE SKILL
analyzer = registry.get("tokensentry-analyzer")
result = analyzer.execute(prompt="YOUR PROMPT HERE")
print(result)

# RUN WORKFLOW
from tokensentry.workflows import WorkflowRunner
runner = WorkflowRunner()
result = runner.run("standard", prompt="YOUR PROMPT HERE")

# CUSTOM WORKFLOW
result = runner.run_custom(
    steps=["tokensentry-analyzer", "tokensentry-optimizer", "tokensentry-validator"],
    prompt="YOUR PROMPT HERE"
)

CREATING CUSTOM SKILLS

EXTEND TOKENSENTRY WITH YOUR OWN DOMAIN-SPECIFIC SKILLS.

SKILL TEMPLATE

# my_skill.py
from tokensentry.skills import BaseSkill, SkillMetadata, SkillResult
from tokensentry.models import Prompt

class MyCustomSkill(BaseSkill):
    METADATA = SkillMetadata(
        name="my-custom-skill",
        display_name="My Custom Skill",
        description="Does something amazing with prompts",
        version="1.0.0",
        author="Your Name",
        category="custom",
        tags=["custom", "example"],
        config_schema={
            "type": "object",
            "properties": {
                "option1": {"type": "string", "default": "default_value"}
            }
        }
    )

    async def execute(self, prompt: Prompt, **kwargs) -> SkillResult:
        # YOUR LOGIC HERE
        analysis = self.analyze(prompt.text)
        
        return SkillResult(
            success=True,
            data={"analysis": analysis},
            metadata={"tokens_processed": len(prompt.text.split())}
        )

    def analyze(self, text: str) -> dict:
        # IMPLEMENT YOUR ANALYSIS
        return {"custom_metric": len(text)}

# REGISTER
from tokensentry.skills import register_skill
register_skill(MyCustomSkill)

LOADING CUSTOM SKILLS

# .tokensentry.yaml
skills:
  auto_load: true
  directories:
    - "./custom-skills"
    - "/path/to/skills"
  default_skills:
    - "tokensentry-analyzer"
    - "tokensentry-optimizer"
    - "my-custom-skill"

BEST PRACTICES

  • IMPLEMENT BaseSkill INTERFACE
  • DEFINE SkillMetadata WITH JSON SCHEMA CONFIG
  • RETURN SkillResult WITH SUCCESS FLAG
  • HANDLE ERRORS GRACEFULLY
  • USE TYPE HINTS FOR BETTER IDE SUPPORT
  • ADD UNIT TESTS FOR YOUR SKILL
  • DOCUMENT CONFIG OPTIONS IN METADATA
