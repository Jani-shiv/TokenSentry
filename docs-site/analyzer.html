DETAILED MODULE REFERENCE

STRUCTURE ANALYZER

PARSES MARKDOWN STRUCTURE TO EXTRACT DOCUMENT ORGANIZATION.

DETECTS:

  • HEADINGS (H1-H6) WITH HIERARCHY
  • CODE FENCES WITH LANGUAGE TAGS
  • ORDERED AND UNORDERED LISTS
  • TABLES WITH ROW/COLUMN COUNTS
  • LINKS AND IMAGES WITH DESTINATIONS
  • BLOCKQUOTES AND HORIZONTAL RULES

OUTPUT:

{
  "headings": [{"level": 1, "text": "Title", "line": 1}],
  "code_fences": [{"language": "python", "lines": "10-20"}],
  "lists": [{"type": "unordered", "items": 5, "nesting": 1}],
  "tables": [{"rows": 10, "cols": 3}],
  "links": [{"url": "https://example.com", "text": "Link"}],
  "images": [{"alt": "Diagram", "src": "diagram.png"}]
}
REDUNDANCY ANALYZER

IDENTIFIES THREE TYPES OF REDUNDANCY WITH SIMILARITY SCORING.

TYPES:

  • LINE REDUNDANCY: EXACT OR NEAR-EXACT DUPLICATE LINES
  • PHRASE REDUNDANCY: REPEATED N-GRAMS (DEFAULT 4-GRAM)
  • REQUIREMENT REDUNDANCY: SEMANTICALLY SIMILAR INSTRUCTIONS

CONFIGURATION:

analyzer:
  redundancy:
    min_phrase_length: 4
    similarity_threshold: 0.85
    max_findings: 20
AMBIGUITY ANALYZER

DETECTS VAGUE LANGUAGE THAT LEADS TO INCONSISTENT MODEL OUTPUTS.

PATTERNS DETECTED:

  • RELATIVE TERMS WITHOUT SCALE ("SHORT", "LARGE", "FAST")
  • UNQUALIFIED QUANTIFIERS ("MANY", "FEW", "SEVERAL")
  • MISSING CONTEXT FOR DOMAIN-SPECIFIC TERMS
  • VAGUE ACTION VERBS ("HANDLE", "PROCESS", "MANAGE")
  • AMBIGUOUS PRONOUNS WITHOUT CLEAR ANTECEDENTS

EXAMPLE FINDINGS:

{
  "type": "AMBIGUOUS_RELATIVE_WITHOUT_SCALE",
  "evidence": "short",
  "location": {"line": 5, "column": 12},
  "suggestion": "Specify exact length: 'under 100 words' or 'maximum 2 paragraphs'",
  "confidence": 0.92
}
CONTRADICTIONS ANALYZER

IDENTIFIES MUTUALLY EXCLUSIVE OR CONFLICTING INSTRUCTIONS.

DETECTION TYPES:

  • DIRECT CONTRADICTION: "DO X" VS "DO NOT DO X"
  • MUTUALLY EXCLUSIVE: "USE PYTHON" VS "USE JAVASCRIPT"
  • CONSTRAINT CONFLICT: "MAX 100 WORDS" VS "MIN 200 WORDS"
  • STYLE CONFLICT: "BE CONCISE" VS "PROVIDE DETAILED EXPLANATIONS"
COMPLEXITY ANALYZER

COMPUTES LINGUISTIC COMPLEXITY METRICS FOR COGNITIVE LOAD ESTIMATION.

METRICS:

  • GUNNING FOG INDEX
  • FLESCH-KINCAID GRADE LEVEL
  • COLEMAN-LIAU INDEX
  • AUTOMATED READABILITY INDEX (ARI)
  • SYNTACTIC TREE DEPTH
  • AVERAGE SENTENCE LENGTH
  • VOCABULARY DIVERSITY (TYPE-TOKEN RATIO)
QUALITY SCORER

COMPUTES 6-DIMENSION QUALITY SCORES (0.0 - 1.0) WITH OVERALL AGGREGATE.

DIMENSIONS:

  • CLARITY: UNAMBIGUOUS LANGUAGE, DEFINED TERMS
  • COMPLETENESS: ALL REQUIRED ELEMENTS PRESENT
  • STRUCTURE: LOGICAL ORGANIZATION, PROPER FORMATTING
  • CONCISENESS: MINIMAL REDUNDANCY, EFFICIENT PHRASING
  • ACTIONABILITY: EXPLICIT VERBS, MEASURABLE OUTCOMES
  • OVERALL: WEIGHTED AGGREGATE OF ABOVE
SECURITY AUDITOR

OPTIONAL MODULE FOR PROMPT INJECTION AND SECRET DETECTION.

THREAT CATEGORIES:

  • PROMPT INJECTION ATTEMPTS
  • ROLE OVERRIDE ATTEMPTS
  • SECRET/API KEY LEAKAGE
  • ENCODING/OBFUSCATION BYPASS
  • CHAIN-OF-THOUGHT EXTRACTION
  • UNSAFE OUTPUT REQUESTS

ENABLE:

# CLI
tokensentry analyze prompt.md --enable-security

# CONFIG
analyzer:
  enable_security: true

CLI USAGE

COMMAND LINE USAGE

BASIC

tokensentry analyze prompt.md

WITH TIKTOKEN

tokensentry analyze prompt.md --tokenizer tiktoken:gpt-4

WITH HUGGINGFACE

tokensentry analyze prompt.md --tokenizer hf:meta-llama/Llama-2-7b-hf

FULL ANALYSIS

tokensentry analyze prompt.md \
  --tokenizer tiktoken:gpt-4 \
  --enable-security \
  --enable-quality \
  --format json

STDIN INPUT

cat prompt.md | tokensentry analyze - --format json

SAVE TO FILE

tokensentry analyze prompt.md --output analysis.json --format json
