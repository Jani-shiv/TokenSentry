CLI USAGE

RUNNING BENCHMARKS

RUN ALL BENCHMARKS

tokensentry benchmark run

SPECIFIC PROFILES

tokensentry benchmark run --profiles conservative balanced

LIMIT PROMPTS

tokensentry benchmark run --max-prompts 5

SPECIFIC CATEGORIES

tokensentry benchmark run --categories software_engineering security

WITH TIKTOKEN

tokensentry benchmark run --tokenizer tiktoken:gpt-4

SAVE RESULTS

tokensentry benchmark run --output results.json

REPORT GENERATION

# MARKDOWN REPORT
tokensentry benchmark report results.json --format markdown

# JSON REPORT
tokensentry benchmark report results.json --format json

# COMPARE AGAINST BASELINE
tokensentry benchmark report results.json --compare --format markdown
