# Repository setup checklist

1. Create a public personal GitHub repository named `tokensentry`.
2. Create it empty; do not auto-generate README, license, or gitignore.
3. Replace `<YOUR_GITHUB_USERNAME>` in README with your GitHub username.
4. Review Apache-2.0 attribution and project metadata.
5. Enable Issues and Discussions; enable private vulnerability reporting if available.
6. Add topics: `prompt-engineering`, `token-optimization`, `llm`, `agent-skills`, `context-engineering`, `python`, `open-source`.
7. Protect `main` and require CI checks when collaborators join.
8. Create labels: bug, enhancement, good first issue, help wanted, documentation, analyzer, optimizer, validator, tokenizers, skills, benchmarks, ci, security, triage.
9. Convert `INITIAL_ISSUES.md` into separate GitHub issues.
10. Tag a release only after tests and CI pass.
