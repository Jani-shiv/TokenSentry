Three Engines. One Mission.

Analyze deeply. Optimize smartly. Validate rigorously.

🔍

Analyzer Engine

7 modular analyzers for comprehensive prompt inspection. Each module focuses on a specific aspect of prompt quality.

  • Structure Parsing — Headings, code fences, lists, tables, links
  • Redundancy Detection — Exact lines, phrases, semantic requirements
  • Ambiguity Finding — Relative terms, unqualified quantifiers, vague verbs
  • Contradiction Identification — Direct, mutually exclusive, constraint conflicts
  • Complexity Metrics — Fog Index, Flesch-Kincaid, syntactic depth, vocabulary diversity
  • Quality Scoring — Clarity, completeness, structure, conciseness, actionability, overall
  • Security Audit — Prompt injection, role override, secret leakage, encoding bypass
⚡

Optimizer Engine

Three optimization profiles with full transformation tracking and technical literal preservation.

  • Conservative: Whitespace normalization, exact duplicate removal only
  • Balanced: Phrase consolidation, transition removal, bullet normalization
  • Aggressive: Filler sentence removal, explanation compression, section reorganization
  • Technical literal preservation — code, commands, API keys, model names untouched
  • Transformation delta tracking — every change logged with before/after
  • Multi-pass iteration — re-run until convergence or max iterations
  • Tokenizer-aware — optimizes for specific model vocabulary
✅

Validator Engine

7-status semantic preservation classification with byte-for-byte literal verification.

  • Exact: Byte-for-byte match of technical literals
  • Structural: Semantic equivalence with reorganization
  • Probable: High confidence preservation, minor phrasing changes
  • Uncertain: Ambiguous, requires human review
  • Modified: Intentional change detected with diff
  • Missing: Required element removed during optimization
  • Weakened: Negative constraint relaxed (e.g., "no external APIs" removed)
