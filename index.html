EVERYTHING YOU NEED FOR PROMPT INTELLIGENCE

TOKENSENTRY PROVIDES A COMPLETE TOOLKIT FOR UNDERSTANDING, MEASURING, OPTIMIZING, AND VALIDATING AI PROMPTS — ALL LOCALLY, WITH NO API KEYS REQUIRED.

HOW IT WORKS

THREE COMMANDS. COMPLETE PROMPT INTELLIGENCE.

ANALYZE. OPTIMIZE. VALIDATE. THE WORKFLOW THAT MAKES EVERY TOKEN COUNT.

01. ANALYZE

DEEP PROMPT INSPECTION

  • STRUCTURE PARSING (HEADINGS, CODE, LISTS, TABLES)
  • REDUNDANCY DETECTION (LINES, PHRASES, REQUIREMENTS)
  • AMBIGUITY & CONTRADICTION DETECTION
  • COMPLEXITY METRICS & READABILITY SCORES
  • QUALITY SCORING (6 DIMENSIONS)
  • SECURITY AUDIT (INJECTION, SECRETS, UNSAFE)
  • EXACT TOKEN COUNTING (TIKTOKEN, HF, SENTENCEPIECE)

01

INSTALL TOKENSENTRY

# FULL INSTALL WITH ALL EXTRAS
pip install -e ".[dev]"

# OR SPECIFIC TOKENIZERS
pip install "tokensentry[openai-tokenizer]"
pip install "tokensentry[huggingface-tokenizer]"

# MINIMAL
pip install tokensentry

REQUIRES: PYTHON 3.11+

02

ANALYZE A PROMPT

tokensentry analyze examples/sample-prompt.md

GET STRUCTURE ANALYSIS, QUALITY SCORES, TOKEN COUNTS, AND FINDINGS INSTANTLY.

03

OPTIMIZE & VALIDATE

# OPTIMIZE
tokensentry optimize prompt.md --profile balanced --output opt.md

# VALIDATE
tokensentry validate prompt.md opt.md

CHOOSE CONSERVATIVE, BALANCED, OR AGGRESSIVE. VALIDATE ENSURES REQUIREMENTS PRESERVED.
